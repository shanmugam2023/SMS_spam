# Project Plan

| Phase | Activity | Deliverable |
|---|---|---|
| 1 | Define problem and objectives | Project scope |
| 2 | Prepare labeled SMS examples | CSV dataset |
| 3 | Build TF-IDF text features | Feature matrix |
| 4 | Train and evaluate classifier | Trained model and metrics |
| 5 | Build prediction interface | Streamlit application |
| 6 | Test, document, and publish | Report and GitHub repository |

## Suggested schedule
- Day 1: Problem definition and dataset preparation
- Day 2: Model training and evaluation
- Day 3: Interface implementation and testing
- Day 4: Documentation and GitHub upload

## Completion criteria
The training script runs, the app predicts a message category, documentation is included, and all project files are uploaded to GitHub.
